Construído para automatizar.

Projeto de portfólio independente, com empresas e documentos fictícios. A interface desta versão é servida pelo FastAPI.

Interface web→FastAPI→PostgreSQL

Consistência

Transações, restrições únicas e validações determinísticas.

Processamento assíncrono

Celery + Redis no projeto completo. Desativados nesta hospedagem gratuita.

Qualidade verificável

Testes de integração e concorrência no PostgreSQL, CI e deploy após aprovação.

Escopo da demonstração

Indicadores e histórico iniciais são ilustrativos. O PDF de exemplo passa pelo extrator real, sem gravar em banco público. Next.js, Playwright, OCR e IA são evoluções planejadas.
